## 3. AX 원데이 클래스 4회

회당 4시간, 50명. 과정별로 신청하며 여러 과정을 수강할 수 있습니다. 모든 과정에서 바이브 코딩(Claude Code와 대화하며 만들기)을 직접 해봅니다.

| 회차 | 일정 | 과정 | 결과물 |
|---|---|---|---|
| ① | 11.11 (수) 13–17시 | 나만의 글쓰기 에이전트 만들기 | 경험 DB 기반 자소서·기획서 초안 에이전트 |
| ② | 11.18 (수) 13–17시 | 바이브코딩 활용 데이터분석 레벨업 | 공공데이터 분석 대시보드 웹앱 |
| ③ | 12.29 (화) 13–17시 | 나만의 세컨드 브레인 에이전트 만들기 | LLM Wiki 기반 지식 관리 에이전트 |
| ④ | 12.30 (수) 13–17시 | 나만의 콘텐츠 자동화 에이전트 만들기 | 숏폼 스크립트 에이전트 + 1분 숏폼 + 랜딩페이지 |
