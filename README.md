# 2026 연세대학교 겨울 AX 캠프 — AI 실전 챌린지

> 연세대학교 × 모두의연구소 · 2026 가을·겨울 AX 프로그램 기획
> 웹 페이지: `index.html` (GitHub Pages로 배포)

**AI로 진짜 문제에 도전하는 실전 챌린지.** 강의를 듣고 끝나는 캠프가 아닙니다. 연구 랩은 논문 초안까지, 비즈니스 랩은 사업자 등록과 첫 고객까지 직접 가 봅니다. AI 에이전트를 도구로 삼아 실제 자료와 실제 사용자로 검증한 결과를 3월 3일 챌린저스 데이에서 발표합니다.

- **실전** — 교재 속 예제가 아니라 내 연구 질문, 내 사업자 등록증으로 시작하는 진짜 문제
- **챌린지** — 정답이 없는 과제에 스스로 도전하고, 막히면 퍼실리테이터와 함께 돌파
- **검증** — 디자인씽킹 액션 플랜으로 실제 독자·고객에게 확인받으며 끝까지 완성

| 트랙 | AI 활용 연구 랩 · AI 활용 비즈니스 랩 (트랙당 40명) |
| 캠프 이수 | 1인 21시간 = 집중 교육 15H (3H × 5일) + 온라인 DT 멘토링 3H (90분 × 2회) + 최종 발표 3H |
| 기간 | 2026.11 – 2027.3 (최종 발표 3월 3일 예정) |

|---|---|---|
| 목표 | 연구가 처음인 학생이 논문 한 편이 만들어지는 핵심 과정을 직접 겪고, AI 에이전트를 연구에 적용하는 노하우와 트렌드를 익힌다 | 사업자 등록부터 첫 고객·첫 결제까지 창업의 핵심 과정을 실제로 겪고, AI 에이전트로 1인 사업을 만들고 운영하는 노하우를 익힌다 |
| 핵심 과정 | 연구 질문 → 선행연구 → Research gap → 연구 설계 → 분석 → 논문 작성(IMRaD) → 피어 리뷰 | Pain point → 고객·시장 조사 → 가치제안·린캔버스 → 사업자 등록(1주차 필수) → MVP → 결제·신청 흐름 → 고객 검증 |

## 7. 완료 조건과 수료 기준

| 구분 | AI 활용 연구 랩 | AI 활용 비즈니스 랩 |

| 기획 / 창업 | 연구계획서 1페이지 | 사업자등록증 + 사업 기획 1페이지 (문제정의·린캔버스·KPI) |
| 구현 | 연구 에이전트 | 결제(신청) 가능한 바이브코딩 MVP (배포 링크) |

| 발표 | 디지털 포스터 + 1분 데모 영상 | 피칭 1페이지 + 1분 데모 영상 |
